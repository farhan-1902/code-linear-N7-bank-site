# N7 — The Next Generation of Banking

The official home page for **N7**, a modern core banking platform built for the digital era.

Live site: [code-linear-n7.vercel.app](https://code-linear-n7.vercel.app)

---

## About

N7 is a CodeLinear project built with [Next.js](https://nextjs.org), designed to showcase a next-generation banking experience — fast, flexible, and digitally connected.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Tech Stack

- [Next.js](https://nextjs.org) — React framework
- [Tailwind CSS](https://tailwindcss.com) — Styling
- [Vercel](https://vercel.com) — Deployment
